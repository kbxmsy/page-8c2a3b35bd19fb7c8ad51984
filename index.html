使用场景

资料检索与远程办公

基础版即可覆盖文档、代码托管与会议软件的跨境访问。建议在客户端开启规则分流，让国内站点直连，避免把全部流量送入代理。

流媒体与内容平台

需要稳定解锁时选择旗舰版或团队版。原生解锁依赖对应地区出口，播放前切换邻近节点并关闭可能干扰 DNS 的插件，可减少片源错误。

游戏与实时通讯

旗舰版含 IPLC 游戏优化，适合对延迟敏感的对战与语音。团队版带宽余量更大，适合多人同时在线。仍须遵守游戏与平台自身条款。

客户端选择（重点）

CheapV2 的核心交付是订阅链接，而不是捆绑安装包。先选定系统，再选能导入订阅的客户端，最后才连接节点。以下按纵向步骤给出对照，便于官网下载后一次配好。

步骤 1确认操作系统与是否允许安装第三方应用。iOS 只能使用商店内已上架的客户端；Android、Windows、macOS、Linux 可使用开源图形客户端或内核。

步骤 2按系统选择客户端。Windows 常用 v2rayN 或 Clash Verge Rev；macOS 常用 ClashX Meta 或 Surge；Android 常用 Clash Meta for Android 或 sing-box；iOS 常用 Shadowrocket 或 Stash；Linux 可用 Clash Meta / sing-box 命令行或图形前端。

步骤 3在 CheapV2 用户中心复制订阅 URL（Clash / SIP008 / sing-box 等格式择一）。不要把订阅发到公开聊天；泄露后立即重置。

步骤 4在客户端「配置 / 订阅」中粘贴链接并更新。检查是否拉取到节点列表与分流规则。若列表为空，先核对系统时间与订阅格式。

步骤 5选择节点，开启系统代理或 TUN 模式。TUN 对 UDP 与游戏更友好。连接后用本页下方「操作说明」做一次连通性检查。

操作说明

导入订阅后的检查顺序

1.更新订阅成功，节点数量大于零。

2.延迟测试挑选空闲节点，避免盲目连第一个。

3.打开规则模式：国内域名直连，跨境走代理。

4.访问目标站点或应用；失败则更换协议或地区，而不是反复开关。

日常维护

客户端需保持更新以兼容新协议。流量将尽时减少 4K 串流。多设备共用同一订阅时，关闭不用的 TUN，以免占满同时在线名额。团队版如需固定出口或分流模板，通过工单提交网段与域名列表即可。

常见问题

CheapV2 是 VPN 还是机场订阅？

CheapV2 以机场订阅方式提供节点，可在多种客户端中使用，功能上承担网络加速梯子的角色。它不是单一品牌封闭 VPN App：你可按设备更换客户端，用同一订阅实现分流、策略组与协议切换。

如何从官网完成客户端下载与首次连接？

先开通套餐并复制订阅，再根据系统在「客户端选择」中安装对应软件，粘贴订阅、更新节点、开启代理或 TUN。iOS 必须使用商店应用；桌面与安卓使用官方开源发行版即可。本页下载入口只提供步骤与对照，避免捆绑来源不明的安装包。

基础版、旗舰版和团队版该怎么选？

浏览与三台设备内的轻度使用选基础版（100GB）。需要原生流媒体、游戏 IPLC 与五台设备选旗舰版（300GB）。公司或多人共用、需要高带宽与定制路由选团队版（1000GB / 20 台设备）。年付价格为基础版 ¥150/年、旗舰版 ¥350/年、团队版 ¥850/年。

同时在线设备如何计算？流量不够怎么办？

以实际建立代理隧道的终端数为准，不是累计安装次数。笔记本、手机、路由器若同时连接会占用多个名额。流量按月重置，用尽后加速中断或降级（以当期说明为准），可等待下月或升级套餐。4K 与大文件会显著消耗配额。

订阅泄露或节点连不上怎么处理？

立即在账户内重置订阅链接，使旧地址失效。连不上时依次检查：系统时间、客户端内核版本、订阅格式、是否开启 TUN、本地防火墙，以及节点地区是否被目标站点限制。更换协议或邻近节点通常比反复开关同一条线路更有效。

CheapV2 支持哪些协议与规则？

节点侧常见 Trojan、VLESS、Hysteria 等，具体以当时订阅为准。Clash Meta 与 sing-box 均可导入并使用规则分流。你可以保留国内直连、广告拦截或自定义域名走代理。团队版可提交企业定制路由需求。
